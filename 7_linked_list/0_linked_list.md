## Linked List
- Structure
  - Linked Nodes
    - Node
      - Data
      - Next Pointer

## Advantages
- Memory can be allocated or de-allocated dynamically
- Insertion and Deletion are simpler than array since no shifting is required
- Easy to reorganise the data
- Efficient memory utilization since the size is dynamic

## Disadvantages
- Random access is not possible (like indexes in array)
- Extra memory required to store the pointers
- Search is costly for sorted list (since binary search is not possible)
- Cache inefficiency because memory is not contiguous

## Applications
- Implementation of advanced data structures like stack, queue, graph, hash map
- Forward and backward navigation in browsers, music player, image viewer
- Undo & redo in documents
- In mobile contacts for inserting a new contact alphabetically
- OS: memory management, process scheduling, file system
- LRU cache
